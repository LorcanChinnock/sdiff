# Security Policy

## Reporting a Vulnerability

Report vulnerabilities via [GitHub Security Advisories](https://github.com/LorcanChinnock/sdiff/security/advisories/new) (private, not a public issue).

Include: affected version, reproduction steps, impact. Expect an initial response within 5 business days.

## Supported Versions

Pre-1.0, only the latest commit on `main` is supported.
